# 다이어리 (바이브 코딩 실습)

AI 코딩 도구(Antigravity)로 다이어리 앱을 만들면서,
**두 대의 노트북에서 같은 저장소를 pull / push 하는 것**을 익히는 실습 저장소입니다.

- 실습일: [2026-0X-XX]
- 결과물: [https://agreesin.github.io/ryuwithagree/]

---

## 참여자

| 이름 | 담당 파일 |
|---|---|
| [동의] | `app.js` |
| [류] | `style.css` |
| 공용 | `index.html`, `README.md` |

---

## 실행 방법

설치할 것이 없습니다.

1. 이 저장소를 clone 한다
2. `index.html` 을 더블클릭한다

작성한 글은 서버가 아니라 **브라우저(localStorage)** 에 저장됩니다.
따라서 다른 컴퓨터나 다른 브라우저에서는 내 글이 보이지 않습니다.

---

## 기능 범위

만들 것:

- [ ] 글 작성 (제목 + 본문)
- [ ] 목록 표시
- [ ] 새로고침해도 유지 (localStorage)
- [ ] 삭제
- [ ] 작성 날짜 표시

만들지 않을 것: 로그인, 서버, 데이터베이스, 이미지 첨부, 검색

> 오늘의 목표는 앱을 완성하는 것이 아니라 **pull / push 를 몸에 익히는 것**입니다.
> 기능을 늘리고 싶으면 다음에 혼자 해봅니다.

---

## 작업 규칙

1. **작업 시작 전에 pull 한다.**
2. **20분마다 커밋하고 push 한다.** (알람을 맞춰둔다)
3. **자기 담당 파일만 수정한다.**
4. AI에게 요청할 때는 파일을 못 박는다.
   - 예: `style.css 만 수정해. 다른 파일은 건드리지 마.`
5. AI가 수정한 **파일 목록을 확인한 뒤에** 수락한다.
6. 코드가 동작하는 순간 바로 커밋한다. (되돌아갈 지점 확보)

### 하지 않을 것

- 파일 나누기 / 폴더 구조 바꾸기
- 라이브러리나 프레임워크 추가
- AI가 제안하는 리팩터링·전면 재작성 수락

## 자주 나는 사고

| 증상 | 원인 | 조치 |
|---|---|---|
| push 가 거부됨 (rejected) | 원격에 내가 모르는 커밋이 있음 | pull → 다시 push |
| push 가 거부됨 (403) | 협업자 권한 없음 | 초대 수락 여부 확인 |
| `<<<<<<<` 가 보임 | 충돌 | 에러 아님. 남길 쪽을 고르고 표식을 지운 뒤 커밋 |
| 상대 코드가 사라짐 | AI가 남의 파일을 덮어씀 | 직전 커밋으로 되돌리기 |
| AI가 응답하지 않음 | 사용량 소진 | 역할을 바꿔서 진행 |

**충돌은 사람이 직접 해결한다. AI에게 시키지 않는다.**
