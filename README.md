# 다이어리 (바이브 코딩 실습)

AI 코딩 도구(Antigravity)로 다이어리 앱을 만들면서,
**두 대의 노트북에서 같은 저장소를 pull / push 하는 것**을 익히는 실습 저장소입니다.

일기 내용은 두 사람이 실시간으로 공유합니다.

- 실습일: [2026-08-22]
- 주소: https://agreesin.github.io/ryuwithagree/

---

## 참여자

| 이름 | 담당 파일 |
|---|---|
| [동의] | `app.js` |
| [류] | `style.css` |
| 공용 | `index.html`, `README.md` |
| 손대지 않음 | `store.js` |

## ⚠️ 먼저 읽을 것

이 앱에는 로그인이 없습니다. **주소를 아는 사람은 누구나 일기를 읽고 쓸 수 있습니다.**

- 실명, 연락처, 주소, 정말 사적인 내용은 쓰지 않습니다.
- 실습용 저장소입니다. 진짜 일기장으로 쓰지 않습니다.

---

## 실행 방법

설치할 것이 없습니다.

- 위 주소로 접속하면 바로 쓸 수 있습니다.
- 처음 열면 이름을 물어봅니다. 이 이름이 일기에 표시됩니다.

`index.html`을 더블클릭하는 방식은 **동작하지 않습니다.**
확인은 항상 위 주소에서 합니다.

---

## 구조

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면의 뼈대 |
| `style.css` | 화면 꾸미기 |
| `app.js` | 버튼 동작, 목록 그리기 |
| `store.js` | 저장·공유 (Firestore) |

**코드는 GitHub로 오가고, 일기 내용은 Firestore로 오갑니다.**

- 코드를 고쳤으면 → push 해야 상대에게 전달됩니다
- 일기를 썼으면 → 아무것도 안 해도 상대 화면에 바로 뜹니다

## 작업 규칙

1. **작업 시작 전에 pull 한다.**
2. **20분마다 커밋하고 push 한다.** (알람을 맞춰둔다)
3. **자기 담당 파일만 수정한다.**
4. **`store.js` 는 아무도 건드리지 않는다.** 여기가 망가지면 앱 전체가 죽는다.
5. AI에게 요청할 때는 파일을 못 박는다.
   - 예: `style.css 만 수정해. 다른 파일은 건드리지 마.`
6. AI가 수정한 **파일 목록을 확인한 뒤에** 수락한다.
7. 코드가 동작하는 순간 바로 커밋한다.

### 하지 않을 것

- 파일 나누기 / 폴더 구조 바꾸기
- 라이브러리나 프레임워크 추가
- `index.html`에서 `type="module"` 지우기
- AI가 제안하는 리팩터링·전면 재작성 수락

## 자주 나는 사고

| 증상 | 원인 | 조치 |
|---|---|---|
| push 가 거부됨 (rejected) | 원격에 내가 모르는 커밋이 있음 | pull → 다시 push |
| push 가 거부됨 (403) | 협업자 권한 없음 | 초대 수락 여부 확인 |
| `<<<<<<<` 가 보임 | 충돌 | 에러 아님. 남길 쪽을 고르고 표식을 지운 뒤 커밋 |
| 상대 코드가 사라짐 | AI가 남의 파일을 덮어씀 | 직전 커밋으로 되돌리기 |
| 일기가 안 보임 / 저장 안 됨 | 인터넷 또는 DB 문제 | F12 → Console 의 빨간 글씨 확인 |
| AI가 응답하지 않음 | 사용량 소진 | 역할을 바꿔서 진행 |

**충돌은 사람이 직접 해결한다. AI에게 시키지 않는다.**
